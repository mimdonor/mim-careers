Web Developer Intern

Websites & web applications · Chennai

About the role

Mission India Movement is looking for an enthusiastic Web Developer Intern to help develop, maintain, and enhance our websites and web applications. You’ll work on practical projects supporting missionary activities, internal operations, digital platforms, and organizational initiatives.

Key responsibilities

  • Develop and maintain responsive websites using HTML5, CSS3, and JavaScript.
  • Build and enhance web applications using React.js and Next.js.
  • Connect frontend applications to REST APIs, backend services, and third-party tools.
  • Create reusable UI components and user-friendly interfaces.
  • Assist with forms, dashboards, authentication, data management, and database integrations.
  • Integrate services such as email, notifications, Google services, and other external APIs.
  • Debug issues, test features, and improve performance and accessibility.
  • Use AI-assisted development or “vibe coding” tools to prototype, generate, debug, and improve code—while reviewing and understanding the results.
  • Collaborate on mobile applications, backend work, and other technical projects when needed.

Technical skills

Core: HTML5, CSS3, JavaScript (ES6+), React.js / Next.js fundamentals, REST APIs, JSON, HTTP methods, responsive design, Git and GitHub, and basic SQL / NoSQL concepts.

Nice to have: Node.js, TypeScript, Tailwind CSS, Postman, authentication, Vercel or similar deployment platforms, Figma, and AI tools such as GitHub Copilot, ChatGPT, Cursor, or equivalents.

What we’re looking for

  • B.E. / B.Tech. / B.Sc. IT, Computer Science, or related student.
  • Interest in web development, problem-solving, and learning new tools.
  • Ability to understand requirements, debug issues, and explain your work.
  • Responsible use of AI tools rather than blindly copying generated code.
  • Good communication, teamwork, and reliability.

What you’ll gain

Hands-on experience with live websites and production applications, full-stack concepts, API and third-party integrations, AI-powered development workflows, mentorship, code reviews, and collaborative practices.

Experience level: Advanced knowledge of every listed technology is not expected. A good foundation, curiosity, and consistent effort are most important.

Mobile App Developer Intern

React Native · Cross-platform apps · Chennai

About the role

Mission India Movement is seeking a motivated Mobile Application Developer Intern to support the development, maintenance, and enhancement of mobile applications using React Native. You’ll contribute to mobile solutions for missionary activities, communication, internal operations, and digital engagement.

Key responsibilities

  • Develop, maintain, and enhance mobile apps using React Native and JavaScript.
  • Build clean, responsive, reusable mobile UI components.
  • Integrate apps with REST APIs, backend services, and external tools.
  • Implement features such as login, user profiles, forms, data displays, and navigation.
  • Work with local storage, state management, and asynchronous API data.
  • Explore push notifications, file uploads, camera access, device permissions, and third-party SDKs.
  • Debug, test, and improve app reliability and performance.
  • Use AI-assisted development or “vibe coding” tools for prototyping, feature development, troubleshooting, and code optimization, with proper review and testing.
  • Coordinate with web developers on shared APIs and features, and assist with web/backend projects when needed.
  • Help with Android/iOS builds and app release workflows.

Technical skills

Core: JavaScript (ES6+), React fundamentals, React Native basics, mobile UI and navigation, REST APIs, JSON, asynchronous programming, Git and GitHub, and basic debugging.

Nice to have: TypeScript, Expo or React Native CLI, React Hooks, state management, Firebase, AsyncStorage, authentication and secure token handling, Android Studio, Xcode, push notifications, and AI tools such as GitHub Copilot, Cursor, or ChatGPT.

What we’re looking for

  • B.E. / B.Tech. / B.Sc. IT, Computer Science, or related student.
  • Interest in mobile app development and modern cross-platform technologies.
  • Basic programming knowledge and a willingness to troubleshoot independently.
  • Responsible use of AI-generated code with appropriate review and testing.
  • Good teamwork, communication, and willingness to contribute across projects.

What you’ll gain

Practical experience with React Native, API integration, mobile device features, testing and debugging, app build and release processes, AI-powered development, and collaborative full-stack projects.

Experience level: Prior experience building a complete mobile app is not mandatory. Programming fundamentals, interest, and a willingness to learn are key.
